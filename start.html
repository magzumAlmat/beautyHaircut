🪄 Beauty Haircut Generator — Запуск сервиса

Изменяйте цвет волос на пепельный и создавайте прически с помощью Qwen Image 2.1 или Pillow

📦 Что делает этот сервис:

  • Загрузка фото — перетащите или кликните для выбора изображения
  • 14 причесок — голливудские волны, каре, пикси, волфкат и другие
  • Пепельный цвет волос — процедурная генерация через Pillow (fallback) или Qwen Image 2.1

🚀 Запуск сервиса:

1
Шаг 1 — Откройте этот файл в браузере

Вы уже здесь! Отлично 🎉

2
Шаг 2 — Установка зависимостей (если нужно)

Если у вас есть Node.js, выполните:

cd /Users/billionare/.lmstudio/apps/bionic/projects/d49037d8-47f4-5808-9028-c707de117f8f/workspace/scratchpad/frontend
npm install

(Зависимости уже установлены, если папка node_modules существует)

3
Шаг 3 — Запуск frontend

Запустите:

cd /Users/billionare/.lmstudio/apps/bionic/projects/d49037d8-47f4-5808-9028-c707de117f8f/workspace/scratchpad/frontend
npm run dev --host 0.0.0.0

Затем откройте http://localhost:5174

4
Шаг 4 — Запуск backend (опционально)

Отдельно запустите Python сервер:

cd /Users/billionare/.lmstudio/apps/bionic/projects/d49037d8-47f4-5808-9028-c707de117f8f/workspace/scratchpad
python server.py

Backend слушает на http://localhost:8001 с API для генерации изображений.
