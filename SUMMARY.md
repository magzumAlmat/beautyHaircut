## 🎨 Список причесок (14 стилей)

### Вечерние и торжественные прически (5 стилей):
| ID | Название | Описание |
|----|----------|----------|
| `hollywood_waves` | Голливудские волны | Гладкие, крупные локоны на одну сторону |
| `high_bun` | Высокий текстурный пучок | С объемом у корней и прядями у лица |
| `low_bun` | Низкий гладкий пучок | Строгий, минималистичный |
| `greek_braid` | Греческая коса | Пышное плетение + хвост |
| `french_twist` | Французский твист (ракушка) | Классический валик на затылке |

### Салонные укладки (5 стилей):
| ID | Название | Описание |
|----|----------|----------|
| `blowout` | Брашинг-объем | Фен + круглая щётка |
| `beach_waves` | Пляжные волны (Beach Waves) | Небрежные текстурные локоны |
| `wet_hair` | Эффект «влажных волос» | Подиумная укладка с гелем |
| `high_ponytail` | Высокий хвост | Текстура, начёс или лёгкая завивка |
| `pearl_bun` | Пудровый пучок (Pearl Bun) | Нежный пучок + мягкие пряди |

### Трендовые стрижки (4 стиля):
| ID | Название | Описание |
|----|----------|----------|
| `bob` | Каре / Боб-каре | Классика, с удлинением или рваными краями |
| `cascade` | Каскад и Лесенка | Многоступенчатый объём |
| `pixie` | Пикси | Короткая стрижка с рваными прядями |
| `wolfcut` | Вулфкат / Шегги | Текстурные, растрёпанные слои |

## 📝 Пример работы приложения

1. Пользователь открывает `http://localhost:5174`
2. Перетаскивает фото в зону загрузки
3. Выбирает, например, «Голливудские волны» или «Каре / Боб-каре»
4. Нажимает кнопку «Применить»
5. Backend возвращает изображение с пепельными волосами (через Pillow)
6. Результат отображается в предпросмотре
