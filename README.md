# ✂️ Hair Style Selector — Qwen Image 2.1

## 🚀 Быстрый старт (локально)

### 1. Установка зависимостей

```bash
cd scratchpad
pip install -r requirements.txt
```

**Или для frontend (React):**

```bash
npm install
```

### 2. Запуск backend-сервера (API)

```bash
# В одной терминале:
uvicorn backend:app --reload --host 0.0.0.0 --port 8001
```

**Вариант с Docker:**

```bash
docker-compose up -d
```

### 3. Запуск frontend (React + Vite)

```bash
# В другой терминале:
npm run dev
```

Откроется `http://localhost:5173`.

## 📋 Поддерживаемые прически (24 варианта)

| Категория | Прическа | Описание |
|-----------|----------|----------|
| **Вечерние и торжественные** | Голливудские волны | Гладкие крупные локоны на одну сторону |
| | Высокий текстурный пучок | С объемом у корней + пряди у лица |
| | Низкий гладкий пучок | Строгий лаконичный образ |
| | Греческая коса | Пышное плетение → хвост |
| | Французский твист (ракушка) | Классический валик на затылке |
| **Салонные укладки** | Брашинг-объем | Фен + круглая щетка |
| | Пляжные волны (Beach Waves) | Небрежный текстурный стиль |
| | Влажные волосы | Подиумная укладка гелем |
| | Высокий текстурный хвост | С начесом / легкой завивкой |
| | Идеально прямые волосы | Утюжок + глянец |
| **Трендовые стрижки** | Каре / Боб-каре | Классика или удлиненный боб |
| | Каскад и Лесенка | Многоступенчатый объем |
| | Пикси | Короткая динамичная с рваными прядями |
| | Вулфкат / Шегги | Текстурный многослойный стиль |

## 🔧 Конфигурация (backend)

Файл `scratchpad/backend.py`:

- **`HAIR_COLORS`** — палитра цветов волос:
  - `ash_gray` → `#A8A9AD` (пепельный серый)
  - `light_ash` → `#C0C0C8` (светло-пепельный)
  - `dark_gray` → `#707070` (тёмно-серый)

- **`BOB_STYLES`** — геометрия стрижки боб:
  - центральное пробор, асимметрия влево/вправо
  - слои с углами среза

## 🔌 API (для интеграции)

### `POST /api/generate`

**Тело запроса:**

```json
{
  "image": "data:image/jpeg;base64,/9j/...",
  "style_id": "bob|pixie|wolfcut|hollywood|...",
  "color": "ash_gray"
}
```

**Ответ:**

```json
{
  "success": true,
  "result_url": "/api/download/bob_ash_gray_20260928143502.png",
  "metadata": { "style": "bob", "color": "ash_gray" }
}
```

## 🧪 Локальный тест

```bash
# Запуск backend'а в отдельном терминале:
uvicorn backend:app --reload --port 8001

# Запрос в Postman или curl:
curl -X POST http://localhost:8001/api/generate \
  -F "image=@photo.jpg" \
  -F "style_id=bob" \
  -F "color=ash_gray"
```

## 📝 Примечание

Сейчас реализован **fallback-режим** (процедурная генерация через Pillow), так как PyTorch не установлен в среде. После установки:

```bash
pip install torch torchvision torchaudio
```

и перекомпиляции модели — API будет использовать реальную Qwen Image 2.1.
