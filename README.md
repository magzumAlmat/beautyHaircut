# ✂️ Hair Style Selector — Сервис для изменения цвета волос и причесок

Веб-сервис, который позволяет загружать фото и выбирать из **14 причесок** с изменением цвета на пепельный (ash gray).

## 🚀 Запуск

```bash
cd scratchpad

# Backend (порт 8001) — запустить в отдельном терминале
python backend.py

# Frontend (порт 3000) — запустить во втором терминале
cd frontend && npm install && npm run dev
```

Откройте `http://localhost:3000` в браузере.

## 📋 Список причесок

### Вечерние и торжественные (5)
- Голливудские волны
- Высокий текстурный пучок
- Низкий гладкий пучок
- Греческая коса
- Французский твист (ракушка)

### Салонные укладки (5)
- Брашинг-объем
- Пляжные волны (Beach Waves)
- Эффект «влажных волос»
- Высокий текстурный хвост
- Идеально прямые волосы

### Трендовые стрижки (4)
- Каре / Боб-каре
- Каскад и Лесенка
- Пикси
- Вулфкат (Wolfcut) / Шегги

## 📁 Структура проекта

- `backend.py` — FastAPI сервер, генерирует изображения причесок
- `frontend/` — React + Vite приложение
- `outputs/` — папка для сгенерированных изображений
