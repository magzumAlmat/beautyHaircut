# Backend — Hair Style Selector API (FastAPI + Pillow + Qwen Image 2.1)

## 📦 Установка зависимостей

```bash
pip install -r requirements.txt
```

## 🚀 Запуск сервера

**Запустить backend (порт 8001):**

```bash
python backend.py
```

Сервер запустится на `http://localhost:8001`

---

## 🔌 API Endpoints

### `/api/generate` — Генерация прически

**Метод:** `POST`  
**Content-Type:** `application/json`

#### Запрос:

```json
{
  "image": "http://localhost:3000/preview.jpg",    // URL изображения или base64
  "style_id": "bob",                                  // один из 14 стилей
  "color": "ash_gray"                                 // пепельный цвет волос
}
```

#### Ответ (успех, статус 200):

```json
{
  "success": true,
  "style_id": "bob",
  "color": "ash_gray",
  "result_url": "/api/download/bob_ash_gray_1735456789.png",
  "metadata": {
    "generated_at": "2026-09-28T17:19:32.123456Z",
    "hash": "bob_ash_gray_1735456789"
  }
}
```

#### Ответ (ошибка, статус 500):

```json
{
  "detail": "Ошибка генерации: ..."
}
```

### `/api/download/{filename}` — Скачать результат

**Метод:** `GET`  
Возвращает сгенерированное PNG изображение.

## 🤖 Интеграция Qwen Image 2.1

### Установка модели

Скачайте модель Qwen Image 2.1 в папку `./models/qwen-image-v1.5`:

```bash
# Пример (адаптируйте под свои нужды):
pip install transformers torch torchvision

python -c "from transformers import AutoModelForImage2Image; ... # скачивание модели"
```

### Активация в backend.py

В файле `backend.py` найдите строку:

```python
QWEN_ENABLE = False  ← измените на True
```

И убедитесь, что модель установлена по пути `./models/qwen-image-v1.5`.

### Как работает Qwen Image 2.1 в этом API

1. При вызове `/api/generate` бэкенд сначала пробует сгенерировать изображение через Qwen Image 2.1
2. Если модель доступна и генерация успешна — возвращается результат от Qwen
3. Если модель недоступна (или генерация провалилась) — используется fallback: процедурная генерация через Pillow

**Пример запроса к Qwen:**

```python
prompt = "long wavy hair with Hollywood waves swept to one side, photorealistic"
result = qwen_model.generate(image_url=prompt)
```

---

## 📝 Примечания

- Backend работает на порту **8001**
- Результаты сохраняются в `outputs/` (субпапки `qwen/` и `pillow/`)
- Fallback через Pillow всегда работает — он используется если Qwen недоступен
- Цвет волос по умолчанию: пепельный (`ash_gray`: RGB 168, 169, 173)
